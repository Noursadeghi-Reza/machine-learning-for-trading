# Personal ML4T Workflow

## Purpose

This fork is my personal research and learning environment built around
Stefan Jansen's Machine Learning for Trading repository.

The upstream repository remains the technical baseline.

## Core Components

- Obsidian: research knowledge, learning notes, hypotheses, interpretations
- Hermes: agent/orchestration layer
- Cursor: interactive coding and implementation
- GitHub: technical source of truth
- OpenRouter: model access layer
- MCP: external tool integration

## Source of Truth

- Code / config / tests: GitHub repository
- Research knowledge: Obsidian
- Agent memory: Hermes
- Implementation tasks: GitHub Issues

## Current Phase

Phase 1: Manual workflow

Obsidian
→ Research Idea
→ GitHub Issue
→ Cursor
→ Implementation
→ Tests
→ GitHub
→ Result
→ Obsidian

## Automation Policy

Do not automate the workflow until the manual process is stable and understandable.
